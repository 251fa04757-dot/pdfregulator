PREREQUISITE KNOWLEDGE: Digital Logic Design.
COURSE DESCRIPTION AND OBJECTIVES:
This course covers the basics of modern Computer Organization and Microprocessor. The emphasis 
is on understanding the design of computer and its components. The student will learn the concepts 
of data representation, micro-operations, memory and input output organizations. It also deals with 
the basic architecture, various addressing modes, pin deﬁ nitions, interfacing of 8086 with memory and 
peripheral devices.

Algorithms, and Division Algorithms.

PREREQUISITE KNOWLEDGE: Programming for problem solving, Discrete Mathematical Structures, 
Data Structures.
COURSE DESCRIPTION AND OBJECTIVES:
This course oﬀ ers the basic knowledge required to analyze the asymptotic performance of algorithms. In 
addition, this course provides the knowledge required to solve diﬀ erent problems using suitable design 
strategies such as the greedy method, divide and conquer, dynamic programming, backtracking and 
branch & bound. This course helps to understand the impact of the choice of data structures and algorithm 
design strategies on the performance. This course also provides the understanding of advanced graph 
applications and throws light on tractable and intractable problems.
MODULE-1
UNIT-1 
6L+6T+6P+6SL=24 Hours
INTRODUCTION 
Algorithm, Pseudo-code for expressing algorithms, Performance analysis – space and time complexity; 
Asymptotic notation - big oh notation, Omega notation, Theta notation and little oh notation; Randomized 
Algorithms; (T1-PP: 1-67)
Analysis of recursive algorithms through recurrence relations- substitution method, Recursion 
tree method, Masters Theorem. (R1-96-102, T2-53-66)
Disjoint sets: Disjoint set operations, Union and ﬁ nd algorithms. (T1-PP: 101-111).

Strassen’s matrix multiplication. ; (T1-PP: 127-194)
Greedy Method: Applications - job sequencing with deadlines, Knapsack problem, Minimum cost 
spanning trees. ; (T1-PP: 197-220).

COURSE DESCRIPTION AND OBJECTIVES:
The goal of this course is introduces the fundamental concepts, architecture, protocols, and technologies 
used in modern computer networks. It provides a layered approach to understanding how data is 
transmitted across networks, focusing on the OSI and TCP/IP models, data communication, routing, 
switching, network security, and wireless networking. Emphasis is placed on both theoretical foundations 
and practical implementations, enabling students to analyze, conﬁ gure, and troubleshoot network 
systems eﬀ ectively.

25CS210 DESIGN THINKING AND 
ENGINEERING ORIENTATION
Hours Per Week :
PREREQUISITE KNOWLEDGE: The course requires a basic understanding of Computer Science 
Engineering concepts, problem-solving techniques, and an interest in user-centric design and system 
development. Familiarity with computational thinking and collaborative work is also beneﬁ cial.
COURSE DESCRIPTION AND OBJECTIVES:
This course introduces the principles of design thinking as a systematic framework for problem-solving 
and innovation in engineering, emphasizing user-centric solutions. It provides hands-on experience 
in designing and prototyping software systems and fosters interdisciplinary collaboration. The course 
explores computational thinking, system design, and emerging trends like AI, IoT, and big data, with a 
focus on ethics and sustainability.
The primary objective of this course is to introduce students to the principles of design thinking as a 
structured framework for addressing complex engineering challenges. By focusing on user-centric 
methodologies, students will learn to empathize with end-users, deﬁ ne problems accurately, and 
generate innovative solutions. This course aims to enhance creativity, critical thinking, and collaborative 
problem-solving skills speciﬁ c to software and system design. Students will explore the role of computer 
science engineering in multidisciplinary solutions and its applications in various ﬁ elds like AI, IoT, and 
big data. Additionally, the course emphasizes the importance of hands-on learning through prototyping, 
iterative testing, and user feedback. It also seeks to instill an understanding of ethical considerations, 
sustainability, and inclusivity in technology design and engineering practices.
